About Book Corner

Book Corner is a simple Book Information System created for a college laboratory activity.

It helps users keep track of book titles, authors, categories, and publication years.

Features: Add, view, search, edit, and delete books.

Languages Used: HTML, CSS, and JavaScript.

Storage: Browser Local Storage.
